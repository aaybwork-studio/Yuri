## Directory Purposes

**assets/**
- Purpose: Files served via Shopify CDN, including compiled build outputs.
- Contains: Static images (`Japanese.png`, `background-hero.png`), audio files (`Singing bowl.mp3`, `Sea Waves - Sound Effect.mp3`), videos (`hero-bg-video.mp4`), custom font files (`dia-regular.woff`), and compiled bundles (`yuri-scripts.js`, `yuri-styles.css`).

**config/**
- Purpose: Theme schema controls and options settings.
- Contains: `settings_schema.json` (defines customization inputs for Shopify Customizer) and `settings_data.json` (active configurations selected by merchant).

**frontend/**
- Purpose: Source directory for design styles and dynamic frontend logic.
- Key files:
  - `entry.css`: Base styles, custom font-face declarations, custom resets, and utility classes.
  - `entry.js`: Central script importing Lenis, GSAP, and registering animation triggers.

**layout/**
- Purpose: Master page containers.
- Key files:
  - `theme.liquid`: Main page container injecting headers, footers, stylesheets, and scripts.
  - `password.liquid`: Layout for password-protected storefronts.

**sections/**
- Purpose: Modular page blocks customizable via Shopify Customizer.
- Key files:
  - `custom-introduction-hero.liquid`: Handles page preload and slide-reveal animation frame.
  - `header.liquid`: Customized navigation menu and centered brand monogram.
  - `footer.liquid`: Custom footers.

**snippets/**
- Purpose: Reusable partial templates.
- Key files:
  - `yuri-japanese-logo.liquid`: Inlines Japanese Monogram SVG.
  - `yuri-wordmark-logo.liquid`: Inlines Yuri Wordmark SVG logo.

**templates/**
- Purpose: Page routes.
- Key files:
  - `index.liquid`: Homepage route.
  - `product.liquid`: Individual product details.
  - `cart.liquid`: Shopping cart overview.
  - `collection.json`: Collection routing configuration.

## Naming Conventions

**Files:**
- `custom-*.liquid`: Bespoke sections built specifically for Yuri theme (distinguishing from default Dawn sections).
- `yuri-*.liquid`: Custom snippet files.
- `entry.*`: Pre-compiled developer entrypoints.
- `yuri-*.*`: Compiled production build assets.

**Directories:**
- Plural names reflecting standard Shopify convention layout: `layout/`, `sections/`, `snippets/`, `templates/`.

## Where to Add New Code

**New Page Section:**
- Implementation: Add a new Liquid file in `sections/` using `custom-[name].liquid`. Include a `{% schema %}` section definition at the bottom.

**New Reusable Snippet:**
- Implementation: Add to `snippets/yuri-[name].liquid` and load it via `{% render 'yuri-[name]' %}`.

**New Style rules:**
- Implementation: Add inside [frontend/entry.css](file:///Users/exodus/Desktop/KC/ANTIGRAVITY/Yuri/frontend/entry.css). Run `npm run dev` to watch changes.

**New Client Script logic:**
- Implementation: Import or implement directly in [frontend/entry.js](file:///Users/exodus/Desktop/KC/ANTIGRAVITY/Yuri/frontend/entry.js).

## Special Directories

**assets/**
- Purpose: Serves both raw assets (images, audio, video) and compiled assets generated by Vite build.
- Committed: Yes. Both compiled styles (`yuri-styles.css`) and script bundles (`yuri-scripts.js`) must be checked in to run correctly on Shopify servers.
